# Reporting tables

Numerical tables underlying Appendix S1 of the associated article. `Endpoints.tsv` lists each benchmark with its scoring mode, numbers of mixtures and controls, and summary statistics; `Replicates.tsv` gives the replicate-level values from which the means and standard deviations are computed. The remaining tables hold calibration, sensitivity, ablation, rare-event, reference-based, and archived-library results.

Average precision treats tied scores as a group. The reference consensus averages the two reference-specific scores for each library before metrics are computed.

The archived 18-library comparisons are descriptive. The six pooled-series libraries are technical replicates of one pool, not independent biological samples.
